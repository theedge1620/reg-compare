How to build the dataset
  1. Put the .docx amendment documents to compare in one folder.
  2. Run the analyzer (it sits next to this page): 
    python folder_compare.py "C:\path\to\folder"
    Add --recursive to include subfolders, or -o to choose where the results go.
  3. It writes regdocdiff-folder.json (load it here), regdocdiff-folder.csv, and — when openpyxl is installed — regdocdiff-folder.xlsx with real strikethrough redlines.

Reading dataset…
Current rule text fetched from the eCFR versioner API v1 via /api/versioner/v1/full/{date}/title-10.xml?part={P}&section={P.S} — date from /api/versioner/v1/titles.json up_to_date_as_of. Only paragraphs referenced in the proposed rule are shown; * * * * * spans collapse unchanged text.
Subsections are matched only within the same section — § 50.55a (b)(2) is compared against (b)(2) of § 50.55a alone, never across sections. A * * * marker means the text up to the next listed subsection is unchanged, so it is not compared. A numbered 46.-style instruction precedes the section it names: where amendatory text follows the section heading, that text is compared and the instruction is shown as context; where the instruction stands alone, the instruction itself is compared, against other instructions only. A number without a § (e.g. 2.326 Motions to reopen.) starts a section only if an instruction names it, or it is a Title 10 section in the eCFR whose heading matches — so quantities such as 0.001 rem are read as text. Comparison ignores case, whitespace and smart-quote/dash styling; the redline is verbatim. Files are read entirely in your browser — nothing is uploaded.
folder_compare.py applies the same parsing, section-scoped matching and redline logic as Document Comparison to every .docx in a folder. A subsection is listed when two or more documents carry it with differing text; documents that share identical text are grouped into one variant, and each pair of variants is redlined. Text-vs-instruction differences are shown side by side, never redlined. The dataset is read entirely in your browser — nothing is uploaded.
